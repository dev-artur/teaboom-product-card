# Карточка товара Teaboom.ru

Тестовое задание: вёрстка верхней части карточки товара интернет-магазина чая
[Teaboom.ru](https://teaboom.ru/product/ananasovij-ulun) на примере товара «Ананасовый улун».

## Стек

- HTML5 + семантическая разметка, микроданные Schema.org (`Product` / `Offer`)
- SCSS (модули `@use`, CSS-переменные для токенов)
- Vanilla JavaScript (ES-модули), без фреймворков
- CSS Grid + Flexbox
- Vite — дев-сервер и сборка

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Сборка и локальный просмотр продакшн-версии:

```bash
npm run build    # результат в dist/
npm run preview
```

## Структура

```
├── index.html                    # разметка карточки
├── public/img/                   # изображение товара
└── src/
    ├── js/
    │   ├── main.js               # рендер фасовок, переключение, добавление в корзину
    │   └── product.js            # данные товара и форматирование цен
    └── styles/
        ├── _variables.scss       # токены и брейкпоинты
        ├── _base.scss            # сброс и базовая типографика
        ├── _product-card.scss    # блоки карточки
        └── main.scss             # точка входа
```

## Функциональность

При переключении фасовки обновляются цена, старая цена, процент скидки (на бейдже
у изображения и рядом с ценой), артикул и активное состояние кнопки.

Фасовки реализованы как `role="radiogroup"`: работает выбор мышью и стрелками
клавиатуры, состояние отражается через `aria-checked`.

Кнопка «В корзину» имеет состояния `:hover` и `:active`; по клику показывается
уведомление. Реальная корзина не подключается — по условиям задания.

| 500 г | 01307 | 1 432,00 ₽ | 1 646,00 ₽ |
| 1000 г | 01308 | 2 064,00 ₽ | 2 592,00 ₽ |
| 5000 г | 01309 | 6 320,00 ₽ | 8 710,00 ₽ |

## Адаптивность

Проверено на 1440 px, 768 px и 375 px.

- **Desktop** — две колонки, фасовки в один ряд.
- **Tablet** — две колонки с более узкой галереей, фасовки в один ряд.
- **Mobile** — одна колонка, фасовки сеткой 2 × 2, кнопка на всю ширину.

Вёрстка построена mobile-first, брейкпоинты — `min-width`.

## Детали реализации

- Цветовые токены, шрифт Open Sans, «пилюльная» форма кнопки и кремовый фон
  ценового блока сняты с действующего сайта Teaboom.ru, чтобы карточка не
  выбивалась из общей стилистики.
- Цены форматируются через `Intl.NumberFormat` с русской локалью, скидка
  считается из данных, а не задаётся в разметке.
- Для изображения заданы `width` / `height` и `aspect-ratio` — layout не прыгает
  при загрузке (CLS).
- Учтён `prefers-reduced-motion`, состояния фокуса видимы с клавиатуры.
